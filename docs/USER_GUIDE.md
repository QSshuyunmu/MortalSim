# MortalSim 中文使用指南

## 1. 安装与启动

从同一个 GitHub Release 下载 `Core` 和全部 `Runtime-XX` CUDA ZIP，并将
四个压缩包全部解压到同一个目录。不要只运行其中一个分卷，也不要分别放在
不同目录。

建议先使用 Release 中的 `SHA256SUMS.txt` 校验文件。解压完成后双击
`Start-MortalSim.cmd`，启动脚本会检查运行时是否完整，然后启动仅监听
`127.0.0.1` 的本地服务并自动打开浏览器。

运行结果、设置、日志和导入的模型都写入
`%LOCALAPPDATA%\MortalSim`，不会写入安装目录。卸载时删除解压目录即可；
如需同时清除用户数据，再删除该本地数据目录。

## 2. 首次导入模型

公开包不附带、托管或自动下载模型权重。

1. 打开“设置与诊断”。
2. 确认 CUDA 状态为“就绪”，并检查显卡名称和驱动诊断。
3. 点击“导入 .pth”，选择本机已有的兼容 Mortal 权重。
4. 等待架构校验、严格 state-dict 加载和 CUDA AMP 前向自检完成。
5. 返回分析台，从“推理模型”下拉框选择已导入模型。

模型导入后会按 SHA-256 保存不可变副本。切换模型只影响之后创建的新任务；
历史扩容始终使用原分析记录的精确模型，模型缺失时会拒绝扩容。

## 3. 输入局面

### 局面和点数

- “局目”支持东一局至西四局；当前版本固定自家为庄家。
- “本场”和“供托”默认均为 0。
- 自家、下家、对面点数可编辑，上家点数自动计算，不能直接填写。
- 四家点数必须为非负的 100 点整数倍，并满足：

```text
四家点数之和 + 供托 × 1000 = 100000
```

校验未通过时不能开始模拟。

### 手牌字符串

手牌输入必须恰好包含 14 张牌，最后一张固定视为第一摸。

```text
4567m3477p134066s
```

记号规则：

- `m`：万子
- `p`：筒子
- `s`：索子
- `z`：字牌，`1z` 至 `7z` 依次为东南西北白发中
- `0m`、`0p`、`0s`：赤五

宝牌指示输入一张牌，例如 `9s`。

### 候选第一打与立直

候选可以用逗号、中文逗号或空格分隔，例如：

```text
1s, 6s
```

也可以直接点击牌面加入或移除候选。候选必须存在于当前 14 张牌中。

当配牌 14 张已经听牌时，可以点击候选旁的“立”按钮，将该候选标记为
“打出此牌并宣告立直”。未满足立直条件的候选会在后端校验时被拒绝。

## 4. 模拟设置

- “模拟局数”是每个候选分别运行的局数。
- 建议保持“固定 seed 严格比较”开启，使所有候选使用相同 seed。
- 高级设置可调整起始 seed、Batch 和 Rayon 线程数。
- Batch 主要影响吞吐和显存占用。需要严格复现时应同时保留模型、Batch、
  seed 和应用版本。

点击“开始模拟”后，任务会在后台运行。用户可以继续查看历史结果；右上角
“任务”入口会持续显示进度、吞吐、模型、Batch、GPU 温度、利用率和显存。
取消任务后保留任务元数据，但不会生成伪装成完整结果的记录。

## 5. 阅读结果

结果页首先显示推荐候选、相对参考候选的配对平均局收支差和 95% 置信区间。
“尚不明确”表示当前区间仍跨过 0，不应把样本中的领先直接解释为确定优势。

### 平均局收支

“平均局收支（NAGA 口径）”使用目标玩家视角的本局终局结算。均值同时显示
Student-t 95% 置信区间；候选差值使用相同 seed 的配对样本置信区间。

### 五类终局

每个无错误完成局只会进入一个类别：

1. 自家和牌，其中进一步区分自家荣和与自家自摸。
2. 自家放铳。
3. 流局。
4. 横移动，即他家荣和他家，自家没有参与点数移动。
5. 他家自摸。

错误局单独计数，不进入上述分布。

### 其他指标

总表还包括：

- 平均终局顺位和 1 至 4 位率
- 立直、副露、默听和牌构成
- 平均和牌点、素点、翻数和符数
- 放铳、被自摸、横移动和平均放铳损失
- 立直率、先制/追立、立直后和牌率和立直巡目
- 听牌率、首次听牌巡目、副露率和副露后和牌率
- 55 槽位役种频率与宝牌类枚数
- 五类终局、顺位、配对差值、稳定性和役种热力图

点击终局或役种数量可以打开代表样本抽屉，并按相同模型、规则和 seed
复跑单局。复跑 trace 不一致时会明确标记。

## 6. 历史结果与增加局数

“历史运行”保存已经完成的分析。可以重新打开结果、删除记录，或对当前
统计协议兼容的结果点击“增加局数”。

扩容时：

- 只能输入新增局数和 Batch。
- 手牌、候选、模型、规则和其他语义配置全部继承。
- 新 seed 从原任务已尝试局数之后连续开始。
- 所有候选完成后才会原子合并到原记录。
- 取消、进程退出或任一候选失败时，原结果保持不变。
- 扩容期间可以离开结果页，并从全局任务抽屉随时查看或取消。

## 7. 导出

结果页提供三种导出：

- **Excel**：只包含当前指标总表中的全部统计指标。
- **JSON**：包含完整、版本化的结果协议。
- **HTML**：可脱离 MortalSim 离线打开的静态比较报告。

旧统计口径的历史记录仍可查看，但无法可靠推导的指标会显示“不可用”，
不会填入伪造的 0。

## 8. 隐私与日志

MortalSim 默认完全本地运行，不上传手牌、seed、模型、GPU 遥测或结果。
出现故障时可在 `%LOCALAPPDATA%\MortalSim\logs` 查看日志。提交 Issue 时请
提供应用版本、运行 ID、错误文本和必要日志，不要上传模型权重、个人牌谱或
其他敏感文件。

常见启动和 CUDA 问题见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。
