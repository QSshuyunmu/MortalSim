# 宝牌 → 宝牌指示牌 映射表

用户输入格式保持不变：

```text
宝牌 2p
```

语义：`2p` 是**宝牌（dora）**，即和牌后加分的那张牌。

Bot 传给 MortalSim 前会转换为**宝牌指示牌（indicator）**，即桌面上翻开的那张牌。

## 数牌（万/筒/索）

指示牌 → 宝牌 循环：`1→2→3→4→5→6→7→8→9→1`

| 宝牌(dora) | 指示牌(indicator) |
|---|---|
| 1m/1p/1s | 9m/9p/9s |
| 2m/2p/2s | 1m/1p/1s |
| 3m/3p/3s | 2m/2p/2s |
| 4m/4p/4s | 3m/3p/3s |
| 5m/5p/5s | 4m/4p/4s |
| 6m/6p/6s | 5m/5p/5s |
| 7m/7p/7s | 6m/6p/6s |
| 8m/8p/8s | 7m/7p/7s |
| 9m/9p/9s | 8m/8p/8s |

赤 5（`5mr/5pr/5sr`）按普通 `5` 处理，指示牌为 `4m/4p/4s`。

## 字牌（两个独立循环）

### 第一循环：东南西北（1z→2z→3z→4z→1z）

| 宝牌(dora) | 指示牌(indicator) |
|---|---|
| 1z 東 | 4z 北 |
| 2z 南 | 1z 東 |
| 3z 西 | 2z 南 |
| 4z 北 | 3z 西 |

### 第二循环：白发中（5z→6z→7z→5z）

| 宝牌(dora) | 指示牌(indicator) |
|---|---|
| 5z 白 | 7z 中 |
| 6z 發 | 5z 白 |
| 7z 中 | 6z 發 |

## 示例

```text
用户输入：宝牌 2p
转换后：  indicator = 1p（传给 MortalSim）

用户输入：宝牌 9s
转换后：  indicator = 8s

用户输入：宝牌 5z
转换后：  indicator = 4z
```
