# Model Files

The model file is not committed to this repository until redistribution
permission is confirmed. An authorized release build must provide:

```text
Akagi/model_v4_20240308_best_min.pth
```

Verify its SHA256 against `MODEL_MANIFEST.json`. If the model cannot be
redistributed, ship a downloader or a documented first-run installation step
instead of embedding it in a ZIP.
