# Checkpoint Boundary

No model checkpoint is part of MortalSim's public source tree or release
artifacts. MortalSim does not publish a checkpoint source, download location,
or redistribution path.

The model library accepts user-provided local `.pth` files only. Each imported
file is identified by SHA-256 within that user's local installation and is not
uploaded, listed, or shared by MortalSim.

Any future decision to distribute a checkpoint requires a separately reviewed
policy, legal record, and release process. It is deliberately out of scope for
the current public release.
