# Security Policy

MortalSim is designed to listen only on `127.0.0.1` by default. Do not expose
the local API to a network interface unless you understand the implications.

Please report security issues through
[GitHub private vulnerability reporting](https://github.com/QSshuyunmu/MortalSim/security/advisories/new)
rather than opening a public issue with exploit details. Include the release
version, operating system, reproduction steps and relevant logs after removing
private paths, model files, or tokens.
