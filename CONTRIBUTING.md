# Contributing

1. Create a focused branch from the default branch.
2. Run the Python tests, Rust tests and the web typecheck/build locally.
3. Keep simulation behavior and fixed-seed reproducibility unchanged.
4. Do not commit model weights, personal logs, generated binaries, tokens or
   absolute local paths.
5. Include a short test note in the pull request.

User-facing changes should update the relevant document in `docs/`.
